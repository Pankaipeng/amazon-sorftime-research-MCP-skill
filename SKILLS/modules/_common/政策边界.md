# 边界：Listing 图片与文案的最新政策规则

> 导图右上角那个菱形。这是**硬约束**，不是建议。所有模块的输出都要过这一层。

---

## 一、文案红线（任何模块都适用）

| 类型 | 禁用 | 替代写法 |
|---|---|---|
| 绝对化 | 100% / never / always / guaranteed | help reduce / designed to / supports |
| 医疗功效 | cures / treats / heals | supports / may help |
| 环保绝对 | 100% eco-friendly / biodegradable（无认证） | made with recyclable materials |
| 安全承诺 | FDA approved（无认证） | meets [实际标准] |
| 持久承诺 | lifetime / forever / lasts forever | long-term use |
| 夸大排名 | best / #1 / top rated | popular / favored |
| 价格绝对 | cheapest / lowest price | affordable / value |

**AI 最容易犯的是绝对化**。生成完必须扫一遍，命中即改。

---

## 二、标题新规（2026-07 起，美国站）

| 字段 | 限制 | 作用 |
|---|---|---|
| Item Name | ≤ 75 字符（含空格） | 身份识别 |
| Item Highlights | ≤ 125 字符 | 比较辅助，可搜索索引（API: `title_differentiation`） |

两条硬规则：

1. **Highlights 不重复 Item Name 已有的词**——重复不加权，纯浪费
2. **Highlights 不写完整句子、不放促销语**

欧洲站、加拿大站同美国站。日本站及图书/音乐/影音类目以类目 schema 为准，不要套用。

---

## 三、图片规则

| 规则 | 说明 |
|---|---|
| 主图纯白底 | RGB 255,255,255 |
| 主图占比 | 产品占画面 ≥ 85% |
| 主图禁止 | 文字、logo 水印、边框、道具、多角度拼图 |
| 场景图可带文字 | 但不得含价格、促销、联系方式 |
| A+ 图片 | 遵守各模块尺寸要求，不得含站外链接 |

**主图放文字是最常见的违规**，也是最容易被系统降权的。

---

## 四、本模块的检查点

`10-keyword` 输出词库时：

- [ ] 否定清单里的词，有没有误伤相关词的（如否掉 "metal" 连带否掉 "metal hooks"）
- [ ] 品牌词是否单独归组，没有混进机会词
- [ ] 词本身不含夸大词（"best coat rack" 这种词可以进否定，不要进标题）

`50-copy` 输出文案时：

- [ ] 逐条过第一节的红线表
- [ ] 标题 / 亮点字符数合规
- [ ] 主图 brief 里没有要求放文字的

---

## 五、规则会变

上面是 2026-07 的版本。政策更新时：

1. 改这个文件
2. 在 `vendor/amazon-listing-builder/reference/mcp-mandatory-protocol.md` 同步合规清单
3. 重跑 `50-copy` 的 audit

**不要只改一处**——两处不一致时，AI 会随机挑一个执行。
