# 方法 A：竞品 ASIN 反查

> 导图子项：竞品 asin 反查出单词 + 反查竞品 asin 库（增加样本数据）

两件事：**先扩池，再从池子里榨词**。顺序不能反——池子不够大就榨词，得到的只是几个头部竞品的词，那叫抄作业，不叫调研。

---

## A1. 扩池（反查竞品 asin 库）

### 输入

`00-input/竞品asin组.json` 里的 head / direct / new 三类。

### 步骤

```python
# 第一跳：从用户给的每个 ASIN 往外扩
pairs = []
for asin in head:   lvl = 0     # 权重 3
for asin in direct: lvl = 1     # 权重 1
for asin in new:    lvl = 1.5   # 权重 2

for asin, lvl in pairs:
    r = mcp__ss_mcp__asin_competitor({
        "marketplace": "US",
        "asin": asin,
        "size": 20
    })
    # 记录每个候选的来源 ASIN 和层级
```

**只扩一跳。** 二阶扩池的边际收益很低，噪声却指数上升。

### 过滤规则

| 规则 | 动作 |
|---|---|
| 站点不同 | 丢弃 |
| 类目路径前 3 段不一致 | 丢弃（跨类目的"竞品"没有参考价值） |
| `units` < 100 | 丢弃（无销量 = 无稳定词结构） |
| 同品牌不同 ASIN | 归组，**不参与词频**，只在报告里标注"变体" |
| 形态明显不同（wall mount vs freestanding） | **保留**，标 `formDiff=true`，后面算差异化时用 |

### 补池

`asin_competitor` 扩不满 8 个时，用类目补：

```python
mcp__ss_mcp__product_research({
  "request": {
    "marketplace":"US",
    "nodeIdPath":"<类目前三段>",
    "minUnits": 200,
    "size": 50
  }
})
```

从结果里按销量取 Top 10，层级标 L2（权重 0.5）。

### 输出：竞品池表

| ASIN | 品牌 | 层级 | 权重 | 月销 | 价格 | 评分 | 评分数 | 形态 | formDiff | 来源 |
|---|---|---|---|---|---|---|---|---|---|---|

**池子目标 8-15 个。** 少于 5 个 → 报告里写"样本不足，词频仅供参考"。

## A2. 榨词（反查出单词）

### 两个工具，分工不同

| 工具 | 拿到什么 | 关键字段 |
|---|---|---|
| `traffic_keyword` | 该 ASIN **所有带来曝光的词**（自然 + 广告 + 推荐） | `searches`、`rankPosition.position`、`adPosition.position`、`trafficPercentage` |
| `keyword_order` | 该 ASIN **真正出单的词**（按转化分层） | `conversionType`（E/S/L/I） |

**两者的差集最值钱**：有曝光但不出单的词，说明这个词把不对的人带来了——这既是选词问题，也是 Listing 表达问题。

### 调用

```python
for asin in pool:
    mcp__ss_mcp__traffic_keyword({
        "request": {"marketplace":"US", "asin":asin, "size":50}
    })
    mcp__ss_mcp__keyword_order({
        "request": {"marketplace":"US", "asin":asin}
    })
```

### 转化类型怎么用

`keyword_order` 返回的 `conversionType`：

| 类型 | 含义 | 处理 |
|---|---|---|
| **E** 转化优质词 | 竞品靠它赚钱 | 优先抢，进 P0/P1 |
| **S** 转化平稳词 | 稳定贡献 | 进 P1 |
| **L** 转化流失词 | 有曝光但在掉 | 单独看，可能是竞品 Listing 没接住 |
| **I** 无效曝光词 | 只曝光不转化 | 进否定候选 |

**竞品的 L 型词是机会点**：竞品有流量但接不住，说明这个词的需求没被满足好。这类词单独列一张表，是本次调研最有价值的产出之一。

### 输出：竞品词表

| keyword | 来源 ASIN | 层级 | 搜索量 | 自然位 | 广告位 | 流量占比 | conversionType | 出现在几个竞品 |
|---|---|---|---|---|---|---|---|---|

**「出现在几个竞品」是最重要的列**——一个词被 8 个竞品同时吃，说明它是品类基础词；只有 1 个竞品吃，可能是它的品牌词或独特打法。

---

## 注意事项

1. `traffic_keyword` 单次返回有上限，`size=50` 通常够；不够就翻页，别用 `size=500` 硬拉。
2. `rankPosition` / `adPosition` 是对象，取 `.position`，不是直接的数字。
3. 自家 ASIN 也跑一遍，用来做「竞品有、我没有」的差集——这是最直接的补词清单。
