# 方法 E：后台数据校准

> 数据来源：**用户上传的附件**。卖家精灵 MCP 拿不到你店铺和品类的后台数据。

这一路不是"再查一遍"，是**给前四路做对账**。它的价值在三个地方：证明搜索量可信、给出真实转化率、看出趋势拐点。

---

## 一、需要哪两份报表

| 报表 | 后台路径 | 关键列 | 解决什么 |
|---|---|---|---|
| 商机探测器 · Niche 详情 · 搜索词 | 品牌分析 → 商机探测器 → 选细分市场 → 搜索词选项卡 | 搜索词、360 天搜索量、90/180 天增长、点击份额、**搜索转化率** | 转化率、趋势、细分市场边界 |
| ABA · 热门搜索词 | 品牌分析 → 热门搜索词 → 按周 | 搜索频率排名、点击第 1-3 品牌、点击第 1-3 ASIN、点击份额、转化贡献占比 | 谁在吃这个词、真实排名 |

两份都是 csv 导出，原样传即可。**不要自己先清洗**，列名我能认。

---

## 二、字段口径（实测确认）

### 商机探测器

| 列 | 含义 | 注意 |
|---|---|---|
| 搜索量（过去 360 天） | 360 天累计，**不是月** | 除以 12 才能和卖家精灵月搜索量比 |
| 搜索量增长（过去 90 / 180 天） | 小数，0.0921 = +9.21% | 导出里负数前会多一个 `'`，解析时要 strip |
| 点击份额 | 该词总点击里，Top 3 商品占的比例 | 判断垄断度 |
| **搜索转化率** | 搜索后下单的比例 | **本次调研最值钱的一列**，见第四节 |

### ABA

| 列 | 含义 |
|---|---|
| 搜索频率排名 | 官方排名，**只有排名没有绝对值**，数字越小越热 |
| 点击量第 1-3 的品牌 | 该词流量被谁吃 |
| 点击量第 1-3 的商品：ASIN / 标题 / 点击份额 / 转化贡献占比 | 逐个竞品的吃词能力 |
| 转化贡献占比 | 该 ASIN 在该词的成交里占多少 |

导出文件头几行是报告元信息（报告范围、选择周、筛选条件），解析时先找到真正的表头行（含"搜索词"和"搜索量"那行）。

---

## 三、口径校验怎么做

把三个来源放在一张表里对账：

```
卖家精灵月搜索量  vs  商机探测器360天/12  vs  ABA 排名（只看方向）
```

| 差异 | 判断 |
|---|---|
| ±10% 以内 | 两口径一致，**卖家精灵可以直接用**，不用打折 |
| -10% ~ -30% | 常见于下降词（360 天均值高于当下），或类目边界不同 |
| +10% ~ +30% | 常见于上升词 |
| 超过 ±50% | 危险，报告里单独提，不要下结论 |

**实测（海绵架，12 个词）**：头部 4 个词差异 +2.6% / +3.4% / +0.2% / -4.7%，说明卖家精灵的月搜索量可信。尾部词差异到 -24%，那种词只信方向不信绝对值。

**ABA 排名不参与计算**，只做两件事：确认这个词真实存在、确认谁是主要玩家。

---

## 四、搜索转化率怎么用

这是 Niche 报表里唯一能替代"真实转化数据"的字段，也是最容易被忽略的一列。

| 现象 | 含义 | 动作 |
|---|---|---|
| 搜索量中等 + 转化率 ≥ 4% | 意图精准 | **优先打，进 P0/P1** |
| 搜索量很大 + 转化率 < 2% | 泛流量，买家还没想好买什么 | 降级，别当主词 |
| 转化率高但 SPR 也高 | 好词但难上首页 | 用广告打，不指望自然位 |

**实测对比**：`sponge holder for sink` 月搜 21,755、转化 5.33%；`sink caddy` 月搜 125,363、转化 2.70%；`kitchen sink accessories` 月搜 71,536、转化 0.69%。

搜索量差 5 倍，转化率也差 5 倍。**只看搜索量会把预算全砸在最泛的那个词上。**

---

## 五、趋势怎么读

看 90 天和 180 天两列的方向是否一致：

| 90 天 | 180 天 | 判断 |
|---|---|---|
| + | + | 稳定上升，可以跟 |
| + | - | 刚回暖，观察一个周期再说 |
| - | + | 短期回调，不必恐慌 |
| - | - | 真在跌，别把主词压在这上面 |

**实测**：`kitchen sink caddy` 90 天 -4.4%、180 天 -11.3%，是明确下跌；`sink organizer` +28.1% / +17.6%，是真涨；`sink organizer rack for kitchen` 90 天 +85.4% 但 180 天只有 +14.7%，属于突然爆发，要观察。

## 六、输出

在词库里加四列：

```
niche_conv    搜索转化率（小数）
g90           90 天增长
g180          180 天增长
aba_rank      ABA 搜索频率排名
n_src         该词能在几个口径里找到（2 = 双口径，3 = 三口径）
```

`n_src ≥ 3` 的词在排序时可以视为"事实"，`n_src = 1` 的词在报告里标"单口径"。

## 七、没有报表怎么办

不阻塞，但必须在口径声明里写明，并且**降低排序的确定性**：

```markdown
- 后台数据：未提供
- 影响：转化类结论无法验证，P0/P1 仅基于估算搜索量排序
- 建议：补一份商机探测器搜索词表 + ABA 热门搜索词，可把 P0 判定准确率显著提高
```

**不要用搜索量高就推断转化好。** 实测里这两个数的相关性很弱。
