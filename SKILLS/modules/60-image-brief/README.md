# 60 · 图片 brief

图片 brief 是给美工执行和复核的逐图设计需求。用本品事实确定能展示什么，用卖点库选题，用证据链解释每张图如何帮助买家判断。

## 输入与转换规则

1. **先锁事实。** 读取 SKU/变体事实清单及 `SP-10`。型号、颜色、结构、装法、尺寸与单位、包装件名与数量、所宣称性能均回查事实字段或记录。字段缺失、互相冲突或需实测时，注明「待补」及所需证据，相关数字、功能措辞和画面放行留待复核。多个 SKU 共用一图时逐个确认适用事实。
2. **分别得出两组候选。** 本模块在 `50-copy` 交付后运行。文案侧逐条读取同 SKU 的已确认五点和原位次，按 `SP ID` 查回买家问题、主张和本品事实，标记可直接展示、可用画面辅助或暂无可用视觉证据。图片侧按本模块规则独立评估，对齐 `SP-01` 三路汇总、`SP-02` 证据链、`SP-04` 图片排序及 `SP-11` 自检，先得出图片候选卖点、展示机制及建议优先级。竞品五点拆解仍作为三路调研证据的一路。
3. **按三路证据评估图片候选。** 权重为**图片拆解 50%、评论拆解 30%、五点拆解 20%**。首版每路按 0、1、2 给级：0 为已查且未见相关证据；1 为单一或间接证据；2 为多条独立、直接且一致的证据。图片看副图是否直接解释买家问题并有可定位画面，评论看购买顾虑、场景或利益是否具体，五点看独立 ASIN 是否明确主张。近似或复用素材作为同组证据。总分 `50×图片级/2 + 30×评论级/2 + 20×五点级/2`。某路未采集或未判读时记待核，保留缺口与权重，先做候选判断。只有竞品文字声称的图片证据最高为 1。分数用于选题和取舍。
4. **先比较，再按购买转化率定案。** 用 `SP ID` 和买家问题对照两组候选，标出一致、表达方式不同、仅一侧有、主次或顺序不同，并核对本品依据与可用画面。以购买转化率为共同目标，依次判断该卖点是否解决关键购买顾虑、画面能否直接且准确说明、与其他图是否重复，再决定保留、合并、补充、替换、暂缓或调序。两组结论一致时可沿用五点相对顺序。差异影响核心主张或强调顺序时，在定案前标出并记录两侧原方案、证据、最终决定及待验证的转化影响。没有实测数据时将转化影响写作假设。每张自由副图聚焦一个买家问题，最终方案写清保留卖点、相对顺序与视觉证明。50 的最终五点与 60 的图片 brief 分别交付，五点修订走 50 的流程。

## 成交指标与权重复核

成交是总目标。主图 brief 交付 A/B 两套合规 MAIN 方案，写明共同点击假设、唯一主要对照变量、其余须保持一致的画面条件，以及两套的摆放和验收要求。按同一 SKU、可比曝光口径看 CTR，同时跟踪每千次曝光产生的订单和详情页购买转化；CTR 提升但单位曝光订单下降时，复核首图吸引的人群和商品是否匹配。曝光与订单数据无法按试验组对应时标明指标不可用，先保留假设。副图方案看同口径的详情页购买转化和订单；没有逐图数据时，用整套副图的版本对照来判断效果。记录站点、SKU、流量口径、价格与促销等变化。

实验前写清基线、最低有意义的变化、可按版本归因的指标、样本或结束条件和判胜口径。主图定版后，再单测副图前段的卖点顺序；只变更要验证的顺序，其余内容保持一致。

`50/30/20` 是默认。建议同时跑 `40/40/20` 作对照：有多条独立评论明确指出同一购买顾虑、使用障碍或退货原因，且本品事实与可拍证据能回答该问题时，复核改变入选结果的卖点。记录取舍理由，按用户确认或同口径成交结果决定是否调整正式权重。技术规格、曝光和评论条数各保留自己的统计口径。

## 固定模块与 7–9 张配额

| 模块 | 设计 brief 要写的内容 |
| --- | --- |
| 主图 | 固定 1 个正式 MAIN 图位，交付 A/B 两套候选轮替，数据指标 CTR。两套均写清缩略图点击重点、背景、主体视角和摆位、随附件摆位及遮挡要求。写到道具时逐件说明用途、前后左右位置、是否随附、与主体关系及适用版本。场景方案仅在适用站点与商品类型有官方依据时列为正式 MAIN 候选。 |
| 尺寸与包装清单 | 写我们卖的尺寸、测量方向与单位，以及每件随附物名称和数量，引用实测与包装清单。可合成 1 张，也可按可读性拆成 2 张。只提供常规尺寸或包装信息时作为基础图处理。 |
| 无字核心场景 | 固定 1 张副图。写真实使用地点、主体安装与使用状态、道具位置及随附情况。用一个可见的使用动作说明买家如何使用，避免与前段卖点图重复。可沿用主图构图思路，图中文字填「无」。例如水槽架可拍手从独立刷位取出刷子，海绵仍留在原位。 |
| 自由卖点副图 | 每张给出 SP ID、买家问题、已核图中文字、承载证据的角度或动作、所需实拍/素材及可逐项核对的验收条件。 |

正式交付 7–9 个图位，以 1 个正式 MAIN 加 6–8 张副图计算。尺寸/清单合图时安排 4–6 张自由副图，拆图时安排 3–5 张。交付默认用合图 7 张结构，必要时拆开尺寸与包装，或增加独立且证据已核的卖点图。MAIN A/B 分别写一行，共用图位 1，图数统计只给默认版本填正式图位；备用主图和同一图位的变体稿单列。可用素材或事实有缺口时写进待补清单；满足最低图数后放行。

## 设计师交付格式

使用 [空白 Excel 模板](templates/image-design-brief.xlsx) 开始填写。

参考 Sheet1，一行一张图。保留图位/图片内容、产品编号、图片尺寸、风格说明、卖点、图片文字、设计要求、参考竞品八项。增加「数据目标」「本品事实/证据」「验收标准」。设计要求写具体构图、主体和道具摆放、所需素材；参考竞品用 `站点 ASIN#图位`，注明参考的展示手法，有可用原图时嵌入缩略图。支持表内 `待补` 与 `待核` 状态。重要差异及取舍记录在表尾，方便运营复核定案依据。全表自检图数、固定模块、两组候选的对照与取舍、事实来源、图中文字和随附物、主图规范、逐图验收条件。

逐图验收包含手机端检查。MAIN A/B 在相同显示大小下与竞品缩略图并排，核对商品轮廓和关键结构是否可辨。前段卖点副图分别写明要回答的购买问题；按手机实际显示尺寸检查一眼能否看懂配件对应关系、使用动作或关键结构，必要文字无需放大即可读。一个卖点需要多个画面时保留同一任务及相邻图位。

## 美国站 MAIN 在 brief 中的检查项

要求白底 RGB 255,255,255，真实商品、实际颜色与数量、主体约占画面 85%、完整入框、单一视角。只安排适用的实际随附件，移除非随附或会误导购买范围的道具。禁止叠加营销文字、角标、边框、水印或拼图。正式场景 MAIN 仅适用于有官方品类例外的商品类型；当前美国站公开例外清单未包含水槽收纳架，WP650 的场景方案放无字副图或单列候选。其他站点和品类按对应官方规范复核，查不到适用条文时请用户提供。像素按站点/类目和项目要求填写，模板保留可编辑字段。
