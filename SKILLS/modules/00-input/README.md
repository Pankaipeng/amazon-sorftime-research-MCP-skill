# 输入层：三类输入

下游所有模块都从这里取料。**输入不齐，后面的模块就停在原地，不要用猜的补。**

---

## 1. 竞品 ASIN 组（必填）

不是随便给几个 ASIN，而是**分层抽样**——四类各司其职，缺哪类就在报告里标出来。

| 类别 | 数量 | 作用 | 对权重的影响 |
|---|---|---|---|
| **头部竞品** | 1-2 | 定义行业天花板、标题和图片的"标准答案" | ×3（L0） |
| **直接竞品** | 3-5 | 同形态、同价位、同人群，是可替代对象 | ×1（L1） |
| **新品** | 1-2 | 反映近期打法变化，老链接看不到的新词常在这里 | ×2（L1.5） |
| **反查扩池** | 自动 | 从上面三类向外扩一层，补足样本量 | ×0.5（L2） |

**为什么新品要单独给权重**：老品的关键词结构是两年前定型的，新品才反映当下算法偏好。给到 L1.5 是为了不被老品的惯性带偏。

### 交付格式

```json
{
  "marketplace": "US",
  "groups": {
    "head":   ["B0XXXXXXX", "B0XXXXXXY"],
    "direct": ["B0AAAAAAA", "B0AAAAAAB", "B0AAAAAAC"],
    "new":    ["B0NNNNNNN"]
  }
}
```

层级固定：`head` → L0（×3）、`direct` → L1（×1）、`new` → L1.5（×2）、扩池 → L2（×0.5）。

### 反查扩池

用 `mcp__ss_mcp__asin_competitor` 从上面每个 ASIN 扩，只扩一层，不要递归：

```python
for asin in head + direct + new:
    mcp__ss_mcp__asin_competitor({"marketplace":"US","asin":asin,"size":20})
```

扩出来的按规则过滤：同站点、类目路径前 3 段一致、月销 ≥ 100、排除同品牌变体。

**池子目标 8-15 个**。少于 5 个 → 词频不可信，报告里必须写"样本不足"。

## 2. 本品事实卡（必填）

没有这张卡，后面所有"差异化"都是空话。

| 字段 | 必填 | 说明 | 用在哪 |
|---|---|---|---|
| 产品定位 | ✅ | 一句话：卖给谁、解决什么、凭什么 | 相关性 R1 判定 |
| 材质 / 工艺 | ✅ | 具体到材料名称，不要"优质材料" | 差异化强度 D |
| 产品参数 | ✅ | 尺寸、数量、重量、承重、颜色等可验证项 | 标题规格槽位 |
| 差异点 | ✅ | 竞品没有或做得差的，逐条列 | Highlights、五点 |
| 使用边界 | 建议 | 不能用在什么场景 | 限制条件、退货预防 |

**差异点必须是可验证的事实**。"更耐用"不算，"承重 30 lbs、竞品普遍 15 lbs"才算。

```json
{
  "positioning": "租房人群的免打孔玄关收纳",
  "material": ["solid rubberwood", "steel hooks"],
  "specs": {"hook_count": 5, "load_lbs": 30, "width_in": 16.5},
  "differentiators": [
    {"point": "solid wood 而非 MDF", "evidence": "wood grain photo + supplier spec"},
    {"point": "承重 30 lbs", "evidence": "lab test report 2026-09"},
    {"point": "免打孔安装", "evidence": "adhesive mount included"}
  ],
  "limits": ["不适合潮湿环境", "单钩承重上限 6 lbs"]
}
```

## 3. 数据回流（可选）

有就跑，没有就在报告里标 `DATA_MISSING`，不要影响主流程。

| 数据 | 来源 | 用途 |
|---|---|---|
| 广告数据 | 卖家后台 Search Term Report | 真实转化词、否词依据 |
| 业务数据 | 后台 Business Report | 会话数、转化率，校验关键词热度 |
| 退货分析 | 后台 Return Report | 痛点真值，喂给 30-insight |

**广告搜索词报告是四路采集之外最值钱的一路**——它是唯一带真实转化的数据。有就一定用，而且要单独标出来，不能和方法 A-D 混在一起算。

## 输入检查清单

开工前逐条打勾，缺项写进报告：

- [ ] 竞品 ASIN 三类是否齐全（头部 / 直接 / 新品）
- [ ] 站点是否确认
- [ ] 本品事实卡四项必填是否齐全
- [ ] 差异点是否每条都有 evidence
- [ ] 数据回流有没有，没有就标 DATA_MISSING
