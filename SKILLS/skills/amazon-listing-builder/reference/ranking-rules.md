# 文案权重排序规则

> 适用：Item Name（标题，≤75 字符）、Item Highlights（商品亮点，≤125 字符）、五点描述。
> 前提：已经拿到 `keyword-research` 的 `handoff.md`（里头有权重分 W、相关性 R、差异化清单）。
> 没有这份交接单就先回去跑调研，不要凭感觉排。

---

## 零、一条主线

**权重分 W 决定"谁该出现"，卖点重要性 M 决定"谁先说"。**

- 标题 / Highlights 服从 **W**（搜索价值优先）
- 五点服从 **M**（说服顺序优先）

两者不通用。把五点也按搜索量排，是最常见的错误——五点不是给搜索算法看的，是给正在犹豫的人看的。

---

## 一、标题（Item Name ≤75 字符）

### 1.1 结构

```
[品牌] + [核心品类词] + [差异化属性] + [主场景] + [规格]
```

五个槽位，从左到右权重递减。**槽位顺序固定，槽位内的词按 W 降序。**

### 1.2 填充算法

1. **品牌**：固定占位，不参与排序（品牌词无搜索价值时不占位，改放第一个）
2. **核心品类词**：从 T1 里取 `R ≥ 0.9` 且 W 最高的 1 个，作为品类锚点
3. **差异化属性**：从 T2（R 0.6-0.9）里按 W 降序，能放几个放几个
4. **主场景**：只放 **1 个**场景词，选 W 最高的那个。不要堆 "entryway bathroom bedroom"
5. **规格**：材质 / 数量 / 尺寸，剩多少字符放多少

### 1.3 硬规则

| 规则 | 说明 |
|---|---|
| 权重优先 | 同一槽位内严格按 W 降序，不允许因为"读起来顺"调换 |
| 相关性门槛 | `R < 0.6` 的词不进标题，无论搜索量多大 |
| 冲突剔除 | `R2 = 0`（属性冲突）的词一律不进，例：本品 wall mount，标题不能出现 freestanding |
| 一义一词 | 同一个意思只出现一次。"wood / wooden / solid wood" 三选一，选 W 最高的 |
| 不堆同义词 | 标题塞同义变体是 2019 年的做法，现在只稀释可读性 |
| 字符优先 | 超 75 字符时，**从右往左砍**（先砍规格，再砍场景），不砍核心词和差异化属性 |

### 1.4 3 版怎么分

仍然出 3 版，但差异在**取舍策略**，不在结构：

| 版本 | 策略 | 适用 |
|---|---|---|
| A 权重最大化 | 前 4 槽位全部塞满 W 最高的词 | 广告冷启动、强竞价品类 |
| B 可读性优先 | 差异化属性只留 1 个最强的，其余让给可读性 | 移动端流量为主 |
| C 合规保守 | 去掉所有可能夸大的属性词（heavy duty / professional 等） | 新账号、高风险类目 |

每版都要标注：占了多少字符、P0 词覆盖了几个、放弃了哪些词及原因。

## 二、Highlights（Item Highlights ≤125 字符）

### 2.1 定位

**Highlights 本质是标题的延伸，不是第二段五点。**

- 它**会进搜索索引**（API 字段 `title_differentiation`）
- 它**不应该重复标题已有的词**（重复不加权，纯浪费）
- 它是买家在列表页扫读时的**比较辅助信息**

所以：**遵循标题的全部规则，但优先级换成"差异化 > 搜索量"。**

### 2.2 排序算法

```
Highlights 排序分 H = 差异强度 D × 0.6 + 归一化 W × 0.4
```

**差异强度 D**（来自交接单的差异化清单）：

| D | 判定 | 例子 |
|---|---|---|
| 1.0 | 本品独有，竞品覆盖率 = 0 | 专利结构、独有配件 |
| 0.7 | 本品有，竞品覆盖 < 30% | solid wood（多数竞品是 MDF） |
| 0.4 | 本品有，竞品覆盖 30-60% | 5 hooks |
| 0.1 | 行业普遍都有 | heavy duty |

**归一化 W**：把候选词的 W 除以本组最大值，落到 0-1。

### 2.3 内容选择

按 H 降序取词，逐条转成短语，用逗号分隔。优先收这几类：

1. **独有材质/工艺**（D 高，且是信任来源）
2. **主场景**（若标题已放，则换次场景）
3. **兼容/适配对象**（fits standard planters / holds up to 30 lbs）
4. **包装内容**（pack of 2 / includes hardware）
5. **限制条件**（indoor use only）—— 这条经常被忽略，但能显著降低退货和差评

### 2.4 硬规则

| 规则 | 说明 |
|---|---|
| 不重复标题 | 逐词比对，标题已有的词一律不用（同义变体也算重复） |
| 不写完整句子 | 逗号分隔的短语，不是句子 |
| 不放促销语 | free shipping / best seller / sale 一律禁止 |
| 不放无证据的差异化 | D=1.0 但供应链拿不出证据的，降级或剔除 |
| 限制条件要写 | 有使用边界就写清楚，这是转化率工具不是减分项 |

### 2.5 示例（Coat Rack，125 字符内）

```
✅ Solid wood, holds up to 30 lbs, fits 16 in stud spacing, hardware included, indoor use
❌ Heavy Duty Wall Mount Coat Rack with 5 Hooks for Entryway (重复标题，零增量)
```

## 三、五点描述（Bullet Points）

### 3.1 定位

五点是**购买决策链**，不是卖点罗列。顺序错了，买家在第三点就走了。

### 3.2 卖点重要性 M

```
M = 需求强度 S × 0.45 + 痛点严重度 P × 0.35 + 差异化 D × 0.20
```

| 分量 | 数据来源 | 打分 |
|---|---|---|
| **S 需求强度** | 该卖点支撑词的搜索量合计（来自交接单） | 归一化到 0-1 |
| **P 痛点严重度** | 竞品差评中提及该痛点的比例 | >30%=1.0，15-30%=0.7，5-15%=0.4，<5%=0.2 |
| **D 差异化** | 同 2.2 的差异强度 | 0-1 |

**注意 P 的权重给到 0.35**：差评里反复出现的问题，比搜索量更能决定转化。一个搜索量很大但所有竞品都做得好的卖点，排不到第一。

### 3.3 排序后套决策链

按 M 降序排出卖点，再套进固定的五段结构：

| 位次 | 决策环节 | 回答的问题 |
|---|---|---|
| 1 | 核心价值 | 这东西到底解决我什么问题（M 最高的卖点，通常是最大痛点） |
| 2 | 痛点解决 | 我最担心的那件事，你怎么保证 |
| 3 | 使用场景 | 我能用在哪（具体，不要"anywhere"） |
| 4 | 规格与使用 | 多大、几个、怎么装 |
| 5 | 信任与风险 | 包装、售后、注意事项 |

**第 1 点必须是 M 最高的那个，不能因为"规格好写"就把规格放第一。**

### 3.4 每点的内部结构

```
[加粗短语：卖点主张] + [一句证据] + [一句场景/收益]
```

- 主张：≤ 8 个词，可扫读
- 证据：材料、数据、测试、认证，必须具体
- 场景：让买家对号入座

### 3.5 硬规则

| 规则 | 说明 |
|---|---|
| 一点一主张 | 每点只讲一件事，不做复合句堆砌 |
| 证据强制 | 没有证据的卖点不准进五点，先补证据（见 `workflow/step-3-evidence-library.md`） |
| 禁用空泛词 | premium / perfect / easy to use / great gift / high quality |
| 关键词自然嵌入 | 每点埋 2-3 个 P1 词，不硬塞，读不通就换词 |
| 长度 | 200-300 字符/点，移动端前 3 个词就要能看懂 |
| 不用绝对化 | 100% / never / lifetime —— 合规红线，见 `reference/mcp-mandatory-protocol.md` |

## 四、三者的关系（一张表记住）

| | 排序依据 | 主要数据 | 失败模式 |
|---|---|---|---|
| 标题 | W（搜索量 × 相关性） | 词库 P0 | 堆词、不看相关性、砍核心词 |
| Highlights | H（差异 × 0.6 + W × 0.4） | 差异化清单 | 重复标题、写成句子、放促销语 |
| 五点 | M（需求 × 痛点 × 差异） | 差评 + 词库 P1 | 按搜索量排、没证据、空泛词 |

## 五、自检清单（提交前逐条过）

**标题**
- [ ] 每个词都有 W 和 R，没有凭感觉塞的词
- [ ] 同槽位内严格按 W 降序
- [ ] 没有 R < 0.6 的词
- [ ] 没有属性冲突词
- [ ] 没有同义词重复
- [ ] 字符数 ≤ 75，且超长时是从右往左砍的

**Highlights**
- [ ] 与标题逐词比对，无重复
- [ ] 至少 2 条 D ≥ 0.7 的差异化点
- [ ] 有使用限制的写清了限制
- [ ] 无促销语、无完整句子、无无证据的宣称
- [ ] 字符数 ≤ 125

**五点**
- [ ] 按 M 降序，第 1 点是最大痛点
- [ ] 每点有具体证据，不是形容词
- [ ] 每点 2-3 个 P1 词，读起来自然
- [ ] 无空泛词、无绝对化词
- [ ] 5 点覆盖了完整决策链，没有环节缺失
